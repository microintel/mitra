Backup & Restore

Your data, in a file you control

Everything Mitra remembers — your account, progress, and settings — lives only in this browser, in a local database called IndexedDB. Nothing is sent anywhere. Export it to a file to keep it safe, move it to another browser, or restore it later if it's ever cleared.

Export everything

Downloads a single JSON file with your account, saved progress, and preferences.

Restore from a backup

Choose a file you exported from Mitra before, then bring it back into this browser.
The backup file includes your account record (with a salted, hashed password — never the password itself), so treat it like any other personal file: don't share it, and store it somewhere you trust.
